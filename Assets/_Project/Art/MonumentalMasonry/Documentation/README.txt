Monumental Masonry Kit — 2026-10-31
Unity 6000.3.27f2 / Built-in pipeline

Eight prefabs: giant stone, thick wall, corner, open doorway, buttress, lintel, floor, and assembled RoyalPalace_120x156x78. Use root scale 1. Horizontal wall module 8.4 m; course/module heights 1.4/4.2 m. Door clear opening 5.6 x 4.2 m from ground level. Static architecture has three LODs and independent collision.

Palace base is 120 x 156 m. Tower rises 78 m above a 4 m foundation. Approach/east ramps enlarge the prefab bounds. The capital's original 4.6 x 3.4 m entrance, enclosed hall, open sky shaft and side exit are retained. The prefab supplies architecture and fixed props. NPCs, the movable skylight cover and story controls remain separate in the actual capital scene; connect those when using this shell elsewhere.

Authoring tools: Assets/_Project/Editor/MasonryArchitectureLibrary.cs, ShangRoyalArchitecture.cs, ShangMasonryUpgrade.cs. Main-scene upgrade: Tools > Three Body Traveller > Upgrade Palace To Authored Masonry. Geometry outside the palace is preserved, and the capital scene is backed up first. Tools and story scene are retained in the source repository, not included as dependencies in this asset-only package.
