Environment Expansion Ready — 2026-10-31

Unity 6000.3.27f2, Built-in Render Pipeline.
Import this .unitypackage, then drag prefabs from Assets/_Project/Art/EnvironmentExpansionReady/Prefabs into a scene. Keep root scale at 1. Dimensions are baked in metres, base at local Y=0.

Each static prop has 3 decreasing LODs and independent collision. Doors and shelters are physically open. Oracle bone and waterskin use trigger bounds for pickup detection and are not configured as player-hand attachments. Braziers and wall sconce include live flame, sparks and light.

PyramidEntryPassage is a 48-metre-wide enterable stone study model, with a 14 x 18 metre chamber and raised dais. Origin is chamber centre. Chamber centre and Royal dais anchor mark placements. This is a room-ready study shell. The main capital uses the separately authored 120 x 156 m MonumentalMasonry palace; this generated model does not replace it. Throne, NPCs and story controls are not included in this study shell.

NaturalRidgeV2 is a distant ridge backdrop. Do not use it as a detailed climbable foreground mountain. MeshCollider geometry is static/non-convex; do not add a non-kinematic Rigidbody to static architecture.

Source archives and editable .blend files are retained separately in ArtSource/Environment/. The package contains the usable prefabs, mesh assets, shaders, textures and required effect scripts, not the raw 500k-triangle candidates or story scenes.
