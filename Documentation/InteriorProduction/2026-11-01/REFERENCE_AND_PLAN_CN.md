# 朝歌宫殿内殿：参考核对与补齐清单

本次完成当前内殿盘点、三张同场景基线截图、布置示意和待生成模型提示词。当前交付为制作方案，尚未将这些新增陈设写入正式场景。依据现有约 28×38 米、净高 8.4 米的内殿安排，优先把御座、献历、占卜和观日这几个剧情焦点做完整。

## 参考核对的实际范围

对应剧情位于腾讯版原始 30 集版《三体》第 7 集的游戏部分。[官方 YouTube 入口](https://www.youtube.com/watch?v=TONQ01_IIDw)、[官方 WeTV 入口](https://wetv.vip/zh-tw/play/h31rop8wfso9jnh/d0045rgs9bg-EP07%3A_Tiga_Tubuh) 已核对：当前 YouTube 版本为会员专享，WeTV 播放器未能载入，因此本次没有逐镜头观看，也没有编造镜头时间码。

已检查公开的[游戏场景图转载](https://finance.sina.cn/tech/2023-01-19/detail-imyasptq8757845.d.html)，可见内容主要是荒漠外景。幻熊视觉发布的[概念设计](https://www.zcool.com.cn/work/ZNjY4NTM2MTY=.html) 明确标注“秦王宫”，不能据此断言朝歌殿内也有相同陈设。

本轮进一步核对了小说对应章节[《三体、周文王、长夜》](https://yuannancheng.com/Docs/%E4%B8%89%E4%BD%93/1/4.html)：相关叙事要素包括高台、兽皮、五层木箱沙漏、地面阴阳与卦象、大鼎和开启天窗后的日光。下列具体纹样、家具造型、尺寸、位置与视觉处理属于本项目的设计提案，未标作电视剧已确认的细节。

## 实际缺项与制作顺序

| 优先级 | 要补齐的内容 | 项目当前情况 | 具体做法 |
| --- | --- | --- | --- |
| P0 | 御座与坐姿贴合 | 石块座面、靠背和台阶已经存在；家具缺乏足够的轮廓与近景细节 | 单独生成石木青铜御座，增加兽皮坐垫和兽面扶手；匹配纣王实际臀部、双手、双脚位置。保留原台阶高度，台阶边缘添加磨损 |
| P0 | 御座背景 | 两块石板上仍为简单几何眼纹 | 生成一种兽面雷纹浮雕板，作为成对背景重点；柱面和墙边使用同一套重复纹带与石材细节 |
| P0 | 五层木箱计时沙漏 | 台上现有普通双锥沙漏；库中 BronzeHourglass 也是普通沙漏 | 木箱、五层格、前盖、沙面和沙流分开自建，方便精确计数、开盖和翻转。游戏时间使用剧情变量；视觉翻转服从既有状态机 |
| P0 | 地面演示图 | 目前只有两条观日嵌线 | 在天窗下制作阴阳鱼与六十四卦的程序图形，随姬昌讲解显现。图案保持平整，不占据通行空间 |
| P0 | 献历陈设 | 台桌是简易几何体，七块浅色历简较粗糙 | 复用历箱与甲骨，补木榫、绳结、边缘磨损、零散简片。刻纹作为装饰；需要可读内容时另用校对后的字形 |
| P0 | 炉火、鼎与烟气 | 殿内已有两件精细铜鼎；铜鼎预制体没有火、蒸汽或水面 | 在一件剧情鼎上加炭火、余烬与少量蒸汽；现有四处简易殿内火光可配精细火盆，复用灯光预算 |
| P1 | 墙面和地面层次 | 大面积均匀石材、空白墙面和重复石路纹理 | 增加局部烟熏、磨损和墙脚色差，台阶前铺更规整的石板边带；在边缘布置少量编织席 |
| P1 | 边缘礼器与兵器 | 独立可复用的商朝戈、矛已有；小型礼器尚缺 | 墙边自建木兵器架，复用现有戈矛；新生成爵和觚各一件，控制数量，确保玩家从入口看得清纣王 |
| P1 | 观日与声音 | 可移动天窗已接剧情；日光依赖现有太阳 | 天窗开启后才显示相应浮尘与光路；补火盆、沙流、石板摩擦和室内脚步混响，巨摆低频声可作为空间背景 |
| P2 | 伏羲侧区 | 当前角色枚举和正式场景没有独立伏羲角色 | 若补齐这段剧情，再增加黑袍人物、独立角色编号、脚本、提示词与动作，安排在侧边暗处。此项不属于单纯摆放静态人物模型 |

## 下一批混元额度优先用于四件独立物体

1. **御座**：约宽 2.4、高 2.4、深 1.6 米，先核对轮廓、坐面高度和落座动作。
2. **兽面雷纹浮雕板**：约宽 2.8、高 4、厚 0.22 米，一种模块对应两个主背景实例。
3. **青铜爵**：约 24 厘米高，作为少量近景礼器。
4. **青铜觚**：约 28 厘米高，与爵共用材质方向。

[四件模型的可复制提示词](GENERATION_PROMPTS_CN.md) 已准备，每条均少于 150 字。本次研究没有消耗新生成请求。上一批结束时观测额度剩余 1 次，本次没有重新查询实时额度；完整模型需要经历概念、几何与纹理阶段。

五层沙漏、卦象线条、绳结架、烟火与光束使用本地几何、材质和特效制作，可以保证结构精确和动画控制。

## 集成时的验收约束

- 御座、沙漏等分别保存为预制体，复用已有来源和材质记录；更新现有资产时保留 GUID。
- 内殿主通路至少保持约 3 米净宽，天窗石板行程、内殿台阶与宫殿到池苑的路线继续接受真实 CharacterController 检查。
- 对话时，玩家、姬昌、纣王与实际地面演示图之间保持视线；道具交互经现有剧情状态机连接。
- 火光使用现有灯位预算。小型物件共享材质与 LOD；分别检查殿内白昼、夜晚、近景和移动天窗，复验复苏阶段的性能。
- 使用本页三张固定机位基线做前后对照。它们来自隔离的 Unity 预览场景，属于编辑态几何记录，不冒充原生游戏运行截图。
