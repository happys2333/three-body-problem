## 验证限制

本机运行明确使用离线剧情回退。在线模型的剧情意图、错误阶段拒绝与剧透过滤通过模拟上游测试；未使用真实 DeepSeek 密钥验收角色表现。硬件麦克风、口音和现场噪声仍需实际体验。

合成语音仍有短句的识别偏差。出发台词曾只读第一句，改为逐句合成后已包含后半句。呼喊的合成回环出现“啊，这里”等单字差异；字幕与脚本保留“来这里！”，不能以此数据宣称声音自然度或真实识别准确率已经验收。回环与标点变体选取记录保留原始结果。

## 重跑

先执行 Unity `ActOneProduction.UpdateOpening()`（需要重新应用布景时）和 `ActOneProduction.BuildPlayer()`，再运行 `python3 Tools/run_act_one_checks.py --opening`。`python3 Tools/audit_gobi_opening.py` 检查保存的报告与源文件哈希；已有 `audit_act_one.py` 自动路由到当前版本，`audit_local_voice.py` 在此基础上检查安装模型与语音服务。

源文件发生变化后，哈希检查会提示证据过期。应在重新验证后更新证据，不能只改结果为通过。早期十分钟固定等待版本的报告保留为历史，不能代表当前开场。
