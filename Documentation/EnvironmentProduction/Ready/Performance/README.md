# 试走场运行调整记录

保留早期原始采样，以便区分验证结果与调试过程。它们来自不同的帧率、预热和取景条件，不能据此直接计算材质优化加速比。

| 记录 | 条件与发现 |
| --- | --- |
| [01](attempt-01-uncapped.json) | 无限帧率，20 个视角 P95 超过 16.67 ms；当时还并行进行了编辑器引用检查。 |
| [02](attempt-02-120fps.json) | 120 FPS 上限，19/20 个视角在预算内；主峰 P95 约 17.09 ms。 |
| [03](attempt-03-packed-maps.json) | 合并粗糙度/遮蔽通道并增加预热后，19/20 在预算内；墙饰面视角 P95 约 20.55 ms。此时的雅丹与悬挑巨岩取景被其他山体干扰，不能算作完整画面验证。 |
| [最终运行](../Native/qa.json) | 使用合并材质、120 FPS 上限、每视角 240 帧预热与 360 帧采样，并重新选择无遮挡镜头。20/20 通过，最差 P95 8.79 ms；全部 6 项碰撞检查通过。 |

最终运行没有并行执行 Unity 素材重建、引用遍历或测试。所有最终视角均渲染 LOD0；源码中保留镜头被其他素材包围或遮挡时的失败检查。结果仅覆盖本机的独立素材试走场。
