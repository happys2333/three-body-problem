## Unity 中如何使用

1. **日常拖用**：打开 `Assets/_Project/Prefabs/Architecture/`。其中按 Kenney、Quaternius、KayKit、中式亭、石堡模块和家具分目录；已使用 Built-in Standard 材质。
2. **浏览 CC0 素材**：打开 `Assets/_Project/Scenes/Architecture/Architecture_AssetGallery.unity`，使用 Scene 视图查看中式亭与陈设、中世纪房屋与构件、石堡模块和材质样球。
3. **浏览五栋中式建筑**：打开本地目录中的 `Assets/ThirdParty/LocalOnly/CSStudioChineseBuildings/Prepared/Chinese_Buildings_Gallery.unity`。可用 Prefab 在同目录的 `Prepared/Prefabs/`。
4. **筛选具体模型**：打开 [architecture-model-catalog.csv](architecture-model-catalog.csv)，查看名称、三角形数、准备后的尺寸、Prefab 路径与 `local_only` 标记。

展示场景不在 Build Settings 中；正常运行仍打开 `01_GobiJourney.unity`，从标题页开始。

### 已做的适配

- 已生成 **407 个可拖用 Prefab**：380 个 CC0 原模型、22 个拆分石堡模块、5 个限本地使用的中式模型。
- 外部材质整理为 Built-in Standard；Poly Haven 配置漫反射、法线、AO，并将粗糙度反转后打包到 Standard 的平滑度通道。有金属度图时一并打包。
- 新素材贴图的 Unity 导入上限为 1K，法线与数据贴图分别设置导入类型和颜色空间；原始贴图继续保留。
- 四角亭源模型接近 40 米宽，准备的 Prefab 缩为约 8 米；KayKit 的 RTS 模型统一放大 4 倍。图库为方便对照，还对展示实例另做缩放。
- 原始 FBX 不覆盖。各建筑 Prefab 是美术资源，实际放入主场景时还需围绕可走区域设置简化碰撞、LOD 与交互；目前没有将整套图库塞入主线场景。

## 朝歌与中世纪的选用安排

**朝歌**：先取土墙、灰瓦、木柱与宽台基，保留现有大厅、巨摆和复苏水边的空间关系。中式亭与店铺用于补侧院、入口和远景；屏风、桌椅可作局部陈设。普通中式素材的时代与装饰不直接当作朝歌定稿，店铺招牌、茶桌和华丽雕饰需按剧情美术方向删改。

**王都当前实现**：已采用原创木土建筑和四坡茅草屋顶重新建设独立王都，包含城门、王道、宗庙、民居、作坊、高台王庭与池苑；本地中式店铺包保留为素材备选。详见 [殷商王都制作说明](SHANG_CAPITAL.md)。

**中世纪**：用 Quaternius 墙窗与屋顶构件组织街道，石堡模块围合教堂外广场，Kenney 的摊位、车与喷泉补生活细节。KayKit 完整建筑适合先验证街区密度和轮廓。几套资源画风不同，正式场景先选一套主风格，再统一色彩、尺度与材质。

人物、服装、动作、自由对话与语音仍按原有功能边界接入；建筑素材不会自动完成这些功能。

## 重新获取与检查

```sh
python3 Tools/fetch_architecture_assets.py
```

下载缓存位于已忽略的 `Logs/asset-downloads/architecture/`。脚本从作者页面获取公开的免费版本，不购买付费版，不保存临时下载凭据。CS Studio 的原包缓存及本地解包目录均不进入 Git；共享仓库时保留获取脚本和来源说明。

导入后在 Unity 执行 **Tools → Three Body Traveller → Assets → Prepare Architecture Library**，可重新生成材质、Prefab、图库场景和模型 CSV。工具会保存并恢复原打开场景，不重建剧情场景或更改构建入口。

本轮校验结果见 [architecture-validation.json](architecture-validation.json)：380 个 CC0 模型与 5 个本地模型可加载，407 个准备后的 Prefab 没有缺失网格或不支持的材质。预览使用当前工程实际渲染，未使用商店宣传图替代项目效果。
