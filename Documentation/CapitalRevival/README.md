# 朝歌浸泡复苏与人物持火把规则

本轮已集成到 `Assets/_Project/Scenes/Traveller/02_ChaogeCourt.unity`。七个复苏者使用真实人物模型；纸片来自各自的伏地姿势烘焙网格，材质顶点变形将身体厚度从约 1.2 厘米连续恢复到原来的卧姿体积，再交接同一骨架的 `MX_GetUpProne` 动画并站稳。

## 过程

1. 抵达前保持干燥纸片状态，不会在玩家还在宫殿时播完。
2. 恒纪元复苏阶段、玩家靠近池边约 24 米后开始吸水，颜色变湿并出现局部水纹。
3. 约 8 秒逐渐恢复体积；七人依次错开 0.55 秒，并非一起弹出立体模型。
4. 撑地起身约 8.4 秒，使用每个人采样得到的水面高度修正曲线；随后站稳、回到自然待机。
5. 全员完成后才能记录复苏结果，完成之前的观察请求不会推进剧情。暂停会暂停过程，回到最初时刻可重播。

人物根节点缩放不变。浸泡时禁用站立胶囊和原立体皮肤，恢复时平滑交回同一模型，避免凭空变大、站姿压扁、起身被待机覆盖或身体穿入池底。七人仍在浅池中，不安排穿过池边木栏的退出路线。

## 火把与动作

平民白天自动收起整支火把并释放左手 IK，夜晚再取出；座位或寒冷不再单独使白天角色持火把。浸泡中的人和仍站在池里的复苏者保持空手。玩家按 **T** 的手动火把能力保留，可以在白天主动点亮和收起。

持握约 0.25 秒渐变，不再全天锁定左臂。人群保持各自朝向和错开的待机节奏，短距离行走先转向再逐渐加速；起身过程独占动画控制，避免被移动或闲聊动作截断。

## 检查与使用

- [EditMode 结果](editmode-tests.json)：复苏资产、七个人物起身的水面接触、原有首都路径和人物绑定。
- [交付记录](delivery.json)、[最终原生运行](Native/final/qa.json)。截图与性能仅覆盖本机这一段复苏 / 火把切换，不代表整款游戏性能。
- 运行包：`Builds/CapitalRevivalPreview.app`。正常玩法从戈壁进入朝歌；快速检查时直接打开朝歌场景 Play，按 F8 进入预览，再按右箭头切到复苏池。
- 时长、错开间隔、纸片厚度：`Assets/_Project/Art/CapitalRevival/Revival.asset`。
- 制作入口：`Tools → Three Body Traveller → Prepare Capital Rehydration`。更换起身动画 / 起始采样时刻，或完整重建首都人物后，需重新执行以生成姿势和接地曲线。原场景备份在 `Logs/revival-backups/`。

源人物、贴图和动作沿用项目已有的 Hunyuan / Mixamo 与人群资产来源条件，没有额外生成或购买。
