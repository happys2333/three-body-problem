# 第二轮实机测试与图形设置

测试日期为 2026-11-16。基线是 GitHub `main` 的 `42b91af`，实机使用 macOS、Apple M5 和 Unity 6000.3.27f2。修复及图形功能在基线上开发。

| 项目 | 实机结果 |
| --- | --- |
| 中文输入与在线回复 | 使用系统简体拼音，候选未确认时发送按钮禁用，回车未发出请求。输入「沙漏的作用」后点击发送，纣王在线回复，无 Console 错误。 |
| 朝歌到最终回顾 | 从朝歌入口定位后，按正常移动、对话、观察及剧情计时推进。58 项检查通过，剧情两次真实模型回复，记录三项关键观察，最终到达 `Summary`。 |
| 分辨率与画质 | 960×540、1280×720、1920×1080 窗口及 1920×1080 全屏生效，设置和保存按钮可用。在未配置 AI 时可以保存画质，点击开始仍会要求验证 AI。 |

剧情覆盖历法查验、复苏池、历法失验、长夜、凝华、文明 137 毁灭、再次登录、中世纪质询、三日凌空和最终毁灭。

真实麦克风实测发现系统授权弹窗会中断准备流程，长录音也会使重采样的位置计算溢出。修复后用 MacBook 内置麦克风确认了授权、重新按 F 的提示和实际录音。录音长度现受实际缓冲区约束，重采样使用宽精度计算。播放器程序集通过了 16 kHz、12 秒和 48 kHz、6 秒两项检查，均核对了总帧数和首末采样。

解锁后用扬声器播放普通话测试句，由内置麦克风拾音。实际录音覆盖约 4.8 秒的按键录音和达到 24 秒上限的长录音，两次都成功把音频发给本机识别服务，未再触发数组越界。Vosk 在本机高负载下两次冷启动用了约 30 和 35 秒，一次独立短句识别成功但耗时约 80 秒。预热模型之后，游戏内长、短录音仍都超过识别服务的等待时间，按预期提示重试或打字。本轮通过了实际录音和音频提交，语音转写与后续在线回复尚未通过。

继续复测时，本机 Vosk 转写短参考句耗时 11.7 秒。使用同一台 Mac 的扬声器试音，16 kHz 系统默认麦克风与显式选择的 48 kHz 内置麦克风在关闭设备前后都只返回零采样。macOS 原生录音接口的六秒对照也收到 292,800 个零采样，播放侧电平峰值为 −2.3 dBFS。游戏现在先复制采样再关闭设备，碰到空录音会提示检查输入设备或改用文字，并跳过转写。测试播放器的 AI 设置已通过在线连接验证，仍需直接人声或外接麦克风验证语音转写与纣王在线回复。macOS 和 Windows 的正式播放器 C# 源码已编译通过。

## 图形设置

在「设置 → 显示与画质」保存窗口模式、分辨率、画质档、超分辨率和光追环境遮蔽。超分辨率默认为原生；可用时可选择 FSR 1.0 或 DLSS 的质量、均衡、性能档。FSR 使用 AMD 的 EASU 和 RCAS，只缩小场景渲染，界面保留原生分辨率。DLSS 由 Unity NVIDIA 模块提供，Windows DX12 和支持的 NVIDIA GPU 才显示。遮蔽用支持 DXR 1.1 的显卡在半分辨率查询静态场景几何。Windows 试玩构建优先 DX12，并提供 DX11 回退。

1920×1080、高画质下，FSR 均衡实际以 1129×635 渲染场景。每个场景视角先预热 60 帧，再采样 120 帧。以下是 Apple M5 的 GPU 中位帧耗时。

| 场景 | 原生 | FSR 均衡 |
| --- | ---: | ---: |
| 朝歌 | 8.81 ms | 8.88 ms |
| 中世纪 | 4.74 ms | 4.22 ms |

朝歌的主线程耗时明显高于 GPU 耗时，因此降低渲染分辨率在这次采样中没有改善流畅度。中世纪的 GPU 中位耗时下降约 11%。截图检查确认缩放前后画面方向、亮度和窗口输出尺寸一致。

Windows x64 交叉构建零错误、零警告。打包步骤会补齐引擎附带的 NVIDIA 运行库；对产物中的两个 DLL 核对了 x64 PE 文件头和 SHA-256，并确认 NVIDIA 托管模块已入包。使用 Windows 版 Unity 从「Tools → Three Body Traveller → Build Windows Playtest」构建时会加入 DXR 资源；macOS 交叉构建会禁用光追。用 Unity 随附的 DXC 库独立编译光追内核，生成了 7,324 字节的 Shader Model 6.5 DXIL。DLSS 与 DXR 的实际画面仍需在支持的 Windows 显卡上验收。

FSR 源码来自 AMD v1.0.2，许可证随资源保留。Unity HLSL 适配移除了头文件里八条不使用的 GLSL 扩展指令，EASU 和 RCAS 实现沿用原版。[AMD FSR 源码](https://github.com/GPUOpen-Effects/FidelityFX-FSR/tree/a21ffb8f6c13233ba336352bdff293894c706575) · [Unity NVIDIA DLSS 接口](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/NVIDIA.GraphicsDevice.ExecuteDLSS.html) · [Unity 内联光线追踪接口](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/SystemInfo-supportsInlineRayTracing.html)
