## 操作

- 正常游玩时直接移动鼠标环顾，不再按住右键。鼠标自动锁定并隐藏。
- Esc 打开菜单并释放鼠标；继续旅程后恢复鼠标环顾。语音交谈时也能直接按 Esc 打开菜单。
- Enter 打开文字交谈，鼠标可用、移动和环顾暂停，避免输入时人物走动。Esc 关闭文字交谈后恢复操作。
- F 仍是按住说话、松开发送；语音交谈不会锁住人物行走。
- 打开观察簿、设置、标题或加载界面时释放鼠标。应用失去焦点时释放鼠标并停止输入，重新捕获时丢弃前两帧鼠标位移，避免镜头突然跳转。

## AI 设置

| 选项 | 行为 |
| --- | --- |
| 沿用本地服务配置 | 保留原有网关环境变量与 `--online` 行为 |
| DeepSeek | 预填官方接口和 `deepseek-flash`，使用玩家填入的 Key |
| 自定义接口 | 支持 Chat Completions 兼容的云端或本地模型，玩家填写地址和模型 ID |
| 离线剧情对白 | 明确不请求上游模型，继续使用现有剧情回复 |

可填写 API 地址、API Key、模型名称、回复等待时间和本地服务地址；“操作与声音”页可调整鼠标灵敏度、反转纵向与 NPC 语音回复。

API 地址接受 Base URL（含服务商需要的 `/v1` 前缀）或完整 `/chat/completions` 地址。常见根地址自动补齐路径，完整地址不会重复追加。地址不能内嵌用户名、密码或查询参数，Key 单独填写。

DeepSeek 预设依据[官方首次调用文档](https://api-docs.deepseek.com/)，核验日期为 2026-11-01；模型 ID 可手动更换。自定义模式预填本机兼容地址 `http://127.0.0.1:11434/v1`，对应 [Ollama 官方兼容接口示例](https://docs.ollama.com/api/openai-compatibility)；需要用户另行提供该服务已有的模型，不会自动安装或下载模型。

## 保存、测试与故障

“保存并返回”立即应用到后续 NPC 请求，跨场景继续生效；“取消”和 Esc 丢弃未保存的修改。地址、模型与操作选项保存在本机 PlayerPrefs，API Key 遮挡显示、仅保存在本次游戏进程内，退出游戏后需要重新填写。保存结构没有 API Key 字段，Key 不进入 Unity 场景、项目配置或 Git。

“测试连接”使用当前表单内容，通过本地服务向指定模型发送一次很短的 JSON 测试；测试不会保存设置、加入 NPC 记忆或推进剧情。认证失败、超时、模型/接口不存在、额度限制与响应格式错误有明确提示，不会把离线回退冒充为在线连接成功。实际玩家点击在线测试会使用其服务商的一次 API 请求。

网络 Key 只作为上游请求的认证头使用，不会进入角色提示词、对话历史或 NPC 台词。本地服务不记录请求体，不返回 Key；拒绝 API 重定向，避免认证头被转发给其他主机。自定义模型仍经过原有剧本阶段、角色权限、剧透过滤及对话转交校验，不能借配置更改人物权限。

本功能沿用已有本地对话/语音服务，默认地址为 `http://127.0.0.1:8769`。本轮已更新并重启本项目拥有的服务，保留 Qwen ASR 与 MOSS TTS 后端。启动器现在识别设置协议版本，避免继续复用不支持新设置的旧网关；不会自动关闭不属于本项目的端口占用进程。

## 验证

编辑器、Python 适配器、本地 HTTP 与原生 UI 的结果见 `editmode-tests.json`、`python-tests.json`、`Native/report.json` 和 `delivery.json`。原生检查覆盖四种窗口尺寸、保存/取消、Key 遮挡与不落盘、认证错误、模型实际转接、鼠标捕获/释放、文字交谈及跨场景设置。

最终 43 项 EditMode、30 项 Python 检查通过；45 项原生设置/操作检查与 57 项戈壁开场回归通过，最终构建 0 错误、0 警告。戈壁回归包含合成中文转写自动发送、真实控制器约 103.31 米行走、晒伤/遮阴恢复、植被成灰、日落及独立朝歌转场。代表性戈壁采样平均 11.17 ms、P95 11.53 ms，仅代表该次第一幕视角，不替代全城性能验收。

三幕场景、复苏配置、对话配置、原卫兵预制体与配置与上一轮交付哈希一致；新增脚本 `.meta` 完整，见 `preservation-audit.json`。

测试使用本地模拟上游，验证真实 HTTP 地址、模型 ID 与认证头的传递，不消耗付费额度。此轮没有使用用户真实 Key 验证云端账号，也没有录制硬件麦克风。原有 ASR 合成音频回归单独记录，不把它当作现场麦克风效果。
